Download CA (PEM)

Client trust installation

Install the downloaded CA on each client to avoid certificate warnings.

# Linux (Debian/Ubuntu)
sudo cp enterprise-ai-ids-ca.crt /usr/local/share/ca-certificates/
sudo update-ca-certificates

# Linux (Fedora/RHEL)
sudo cp enterprise-ai-ids-ca.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust

# Firefox
about:config → security.enterprise_roots.enabled = true
# then import the CA from about:preferences#privacy

# macOS
# Keychain Access → System → import → set to "Always Trust"

Enable interception

These commands redirect TCP/443 into the interceptor. Run as root.

# Redirect 443 → interceptor
sudo python -m ssl_inspect.iptables install

# Exclude the IDS host itself (adjust IP)
sudo iptables -t nat -I PREROUTING 1 -s <IDS_HOST_IP> -j RETURN

# When done
sudo python -m ssl_inspect.iptables remove
